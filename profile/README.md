Edgaze is a marketplace and execution layer for AI workflows.

Creators publish executable workflows. Buyers pay per run. Every workflow runs on a hosted runtime and can be used from the web, through the REST API, or by AI agents over MCP.

## How it works

- **Publish:** build a workflow and publish it to the marketplace.
- **Run:** anyone can run it in the browser, with no setup.
- **Integrate:** call it from your own code through the API.
- **Automate:** agents can find, inspect, and run workflows through MCP.

## Public repositories

The core platform is private. These are open:

- 🤖 [**mcp**](https://github.com/edgaze-ai/mcp): lets agents discover, inspect, and run Edgaze workflows.
- 📐 [**edgaze-openapi**](https://github.com/edgaze-ai/edgaze-openapi): OpenAPI 3.1 spec for the Edgaze REST API, kept in sync with production.
- 🎞️ [**edgaze-recordings**](https://github.com/edgaze-ai/edgaze-recordings): the motion and rendering system behind Edgaze product clips.

Read the [developer docs](https://www.edgaze.ai/docs) to run your first workflow from the API or connect Edgaze to your agent.
